# 웹게임 허브

여러 가지 웹게임을 한 곳에서 즐길 수 있는 사이트입니다.

## 게임 목록

- **윷마블** — 윷을 던져 세계 도시에 투자하는 보드 전략 게임 (2~8인)

## 이용 방법

1. 사이트에 접속합니다.
2. 플레이할 게임 카드를 클릭합니다.
3. 게임이 새 창에서 열립니다. 창을 닫으면 허브로 돌아옵니다.

## 기술

- 순수 HTML/CSS/JavaScript (빌드 과정 없음)
- GitHub Pages로 호스팅

## 저작권

이 저장소의 모든 코드와 콘텐츠에 대한 권리는 작성자에게 있습니다.
별도의 라이선스가 부여되지 않았으므로, 작성자의 허가 없이 코드를 복제·수정·배포·상업적으로 이용할 수 없습니다.
